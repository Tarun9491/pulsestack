## 💻 Local Development Setup

### 1. Frontend (Next.js)
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Backend (Optional Node.js server)
```bash
cd backend
npm install
npm run dev
```

---

## 🌐 Deployment (Vercel)

1. Push this repository to GitHub: `Tarun9491/pulsestack`
2. Connect to [Vercel](https://vercel.com)
3. Set Root Directory to `frontend` (or deploy root)
4. Add environment variable `GROQ_API_KEY` (optional)
5. Hit **Deploy**!
